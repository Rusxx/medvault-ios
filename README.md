# MedVault

**MedVault** — нативное iOS-приложение на SwiftUI для локального хранения медицинских документов и личной медкарты. Приложение принимает изображения и PDF, сохраняет оригиналы внутри контейнера приложения, извлекает доступный текст и отображает только информацию, которую удалось найти в исходном документе.

> **Важно.** MedVault не является медицинским диагностическим инструментом и не предоставляет медицинских рекомендаций. Информация извлекается автоматически и может содержать ошибки; её необходимо проверять по оригиналу документа.

## Возможности

MedVault создаёт локальный каталог медицинских документов с отдельными экранами для главной страницы, библиотеки документов, медкарты и приватности. Пользователь может выбрать фотографию через системный Photos Picker, импортировать изображение или PDF из Files и, на реальном устройстве, снять документ встроенной камерой. Для каждого файла приложение сохраняет оригинал, показывает статус обработки, миниатюру, тип и дату; документ можно открыть, повторно обработать при ошибке или удалить вместе с оригиналом.

| Раздел | Реализованная функция |
|---|---|
| Главная | Имя пользователя, счётчики документов, лекарств, аллергий и последняя запись; быстрый импорт и пример данных с явной маркировкой. |
| Документы | Поиск по типу, дата, тип, миниатюра изображения или PDF-предпросмотр, статусы «Не обработан», «Обрабатывается», «Обработан», «Ошибка». |
| Детали документа | Оригинал, извлечённый текст, карточки структурированных значений, копирование текста, повторная обработка и удаление. |
| Медкарта | Редактируемые личные данные, аллергии, заболевания, лекарства и операции. Все записи сохраняются локально. |
| Приватность | Прямое описание локального хранения и отсутствия регистрации, аналитики и рекламы. |

## OCR и извлечение PDF

Для изображений приложение использует `VNRecognizeTextRequest` из Apple Vision с языковыми настройками `ru-RU` и `en-US`, уровнем распознавания `.accurate` и коррекцией языка. Apple указывает, что обработка Vision для распознавания текста выполняется на устройстве; это поддерживает локальный режим приложения.[1] После OCR консервативный локальный парсер пытается выделить только явно присутствующие в тексте дату, врача, учреждение, показатели, единицы, референсные значения, лекарства с дозировками и явно подписанные заключения. Он не подставляет значения, не формирует диагнозы и не делает клинических выводов.

Для PDF применяется `PDFDocument`: текст извлекается из доступного текстового слоя, а первая страница используется для миниатюры и встроенного просмотра. PDFKit предоставляет модель `PDFDocument` и вид `PDFView` для работы с PDF в приложениях.[2] Сканированный PDF без текстового слоя корректно отмечается ошибкой обработки с возможностью повторить операцию; для OCR такого документа пользователь может импортировать его как изображение.

Системный `PhotosPicker` используется для выбора фото из медиатеки, а пользовательский выбор обрабатывается через `PhotosPickerItem` и `Transferable`.[3] Импорт файлов выполняется через системный `fileImporter`; при захвате камеры запрашивается стандартное разрешение iOS.

## Архитектура

Проект следует разделению SwiftUI/MVVM. `AppStore` — единый `@MainActor`-store, который является view model для представлений и координирует импорт, состояние обработки, повторные попытки, удаление и сохранение профиля. Сервисы изолируют ввод-вывод, OCR, PDF и консервативный разбор текста.

```text
MedVault/
├── App/                         # Точка входа SwiftUI
├── Models/                      # Codable-модели документов и медкарты
├── Views/                       # Экраны и навигация
├── ViewModels/                  # AppStore
├── Services/
│   ├── StorageService.swift      # Application Support + JSON metadata
│   ├── OCRService.swift          # Vision OCR
│   ├── PDFService.swift          # PDFKit extraction / preview
│   └── MedicalTextParser.swift   # Только явные текстовые паттерны
├── Components/                  # Общие SwiftUI-компоненты
└── Resources/                   # Asset catalog и Info.plist
```

## Приватность и хранение

Оригиналы документов и JSON-метаданные записываются в `Application Support/MedVault` внутри контейнера приложения. Обработка изображения и PDF не использует сетевой клиент, backend, аналитику, рекламу или учётную запись. Поэтому экран «Конфиденциальность» достоверно сообщает: **«Ваши документы хранятся на устройстве. Приложение не отправляет медицинские документы на сервер.»**

Демонстрационная запись доступна только через меню на главном экране и всегда помечается **«Пример данных»**. В ней нет реальной медицинской информации.

## Требования

Для сборки необходимы macOS, современный Xcode с iOS 17 SDK или новее и доступный iOS Simulator. На реальном устройстве необходимо выбрать свою signing team в настройках target, если Xcode запросит подпись. В проекте не используются CocoaPods, Swift Package Manager или сторонние библиотеки.

## Запуск в Xcode

1. Клонируйте репозиторий и откройте `MedVault.xcodeproj` в Xcode.
2. В списке схем выберите **MedVault** и симулятор iPhone c iOS 17 или новее.
3. Нажмите **Run** (`⌘R`).
4. На главном экране выберите «Добавить медицинский документ», чтобы импортировать изображение или PDF. Камера работает на физическом устройстве; в Simulator предусмотрено понятное уведомление о недоступности камеры.

## Сборка из Terminal

В macOS с установленным Xcode выполните:

```bash
xcodebuild \
  -project MedVault.xcodeproj \
  -scheme MedVault \
  -sdk iphonesimulator \
  -configuration Debug \
  -destination 'platform=iOS Simulator,name=iPhone 16' \
  build
```

Если указанная модель симулятора отсутствует, замените `name=iPhone 16` на устройство из `xcrun simctl list devices available`.

## Ограничения MVP

MedVault не ставит диагнозы, не нормализует показатели и не оценивает результаты анализов. OCR зависит от качества изображения, освещения, языка, шрифта и ориентации документа. PDF с текстовым слоем извлекается напрямую; PDF-сканы не проходят OCR в версии MVP. Локальное хранение не заменяет резервное копирование устройства, а удаление документа из MedVault удаляет его оригинал из контейнера приложения.
